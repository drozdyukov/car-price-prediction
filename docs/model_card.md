# Model Card — прогноз стоимости подержанного автомобиля

## Назначение и версия

| Поле | Значение |
| --- | --- |
| Идентификатор | `car-price-prediction`, версия пакета 0.1.0 |
| Дата описания | 5 октября 2026 года |
| Тип задачи | Регрессия: прогноз цены продажи |
| Модель | `RandomForestRegressor` в scikit-learn Pipeline |
| Артефакт | `artifacts/model.joblib` |
| Единица результата | Лакх индийских рупий; 1 лакх = 100 000 ₹ |
| Базовый год | 2020; возраст = 2020 − Year |

Учебный сценарий: пользователь вводит характеристики транспорта и получает
ориентировочную цену. Модель предназначена для демонстрации ML-процесса,
рефакторинга и воспроизводимого обучения. Оценка на современном рынке,
российском рынке или внешнем независимом датасете не проводилась.

## Данные обучения

Источник в проекте — `data/raw/car_data.csv`, импортированный из выбранного учебного
репозитория. Дата сбора, точный механизм формирования выборки и лицензия первичного
датасета не подтверждены отдельной документацией. Лицензия MIT проекта относится
к коду; она сама по себе не подтверждает условия использования данных.

| Характеристика | Значение |
| --- | --- |
| Число строк | 301 |
| Полные дубликаты сверх первых вхождений | 2 |
| Пропущенные значения | 0 |
| Годы в столбце Year | 2003–2018 |
| Цена нового аналога | 0,32–92,60 лакха ₹ |
| Цена продажи | 0,10–35,00 лакха ₹ |
| Количество предыдущих владельцев | 0–3 |
| Топливо | Petrol: 239; Diesel: 60; CNG: 2 |
| Продавец | Dealer: 195; Individual: 106 |
| Коробка передач | Manual: 261; Automatic: 40 |

В CSV представлены **и автомобили, и мотоциклы**: например, есть строки
Royal Enfield, KTM и Bajaj. Тип транспорта не выделен отдельным признаком.
Поэтому модель не является специально проверенной моделью только для автомобилей,
несмотря на название интерфейса. Полные дубликаты сохранены; в текущем разбиении
одинаковые полные строки не встречаются одновременно в обучающей и тестовой выборках.
Проверка использует все столбцы исходной строки, без индекса.

## Входные данные и подготовка признаков

| Вход | Смысл | Обработка |
| --- | --- | --- |
| `Present_Price` | Цена нового аналога, лакхи ₹ | Числовое значение |
| `Year` | Год покупки в терминологии интерфейса | Преобразование в `Years_old` |
| `Owner` | Число предыдущих владельцев | Числовое значение |
| `Fuel_Type` | Petrol, Diesel или CNG | Индикатор дизеля |
| `Seller_Type` | Dealer или Individual | Индикатор частного продавца |
| `Transmission` | Manual или Automatic | Индикатор механической коробки |

Смысл Year как года покупки либо года выпуска требует уточнения в первоисточнике;
проект использует исходную интерпретацию интерфейса. `Car_Name` и `Kms_Driven`
в модель не входят. **Бензин и CNG имеют одинаковое кодирование**, поэтому различать
эти два вида топлива модель не умеет.

Порядок внутренних признаков:
`Present_Price`, `Owner`, `Years_old`, `Fuel_Type_Diesel`,
`Seller_Type_Individual`, `Transmission_Manual`.

Вход проверяется на обязательные столбцы, уникальность их названий, отсутствие
пропусков, допустимые категории и конечные числа. Цена нового аналога должна быть
положительной, Year — целым числом от 1900 до 2020, Owner — целым неотрицательным
числом. Технически разрешённый диапазон шире фактически наблюдавшегося в обучении;
валидный ввод не гарантирует надёжный прогноз. Итоговая цена проверяется на
конечность и неотрицательность.

## Обучение

Разбиение случайное: `test_size=0.1`, `random_state=42`.
Обучающая выборка содержит **270 строк**, отложенная тестовая — **31 строку**.
Это не временное и не групповое разбиение; отдельной валидационной выборки нет.

Pipeline включает `FunctionTransformer(prepare_features)` и случайный лес.
Текущая предобработка детерминирована: она не вычисляет статистики по выборке.
Регрессор обучается только на обучающей части; целевая цена не входит в признаки.
Обработка признаков сохраняется вместе с моделью и используется при предсказании.

| Параметр | Значение |
| --- | --- |
| n_estimators | 1000 |
| max_depth | 25 |
| min_samples_split | 2 |
| min_samples_leaf | 1 |
| max_features | sqrt |
| random_state | 42 |
| n_jobs | -1 |
| Python | 3.12 |
| scikit-learn | 1.9.1 |

Параметры перенесены из существующей модели учебного проекта.
В текущем производственном скрипте новый подбор параметров не выполняется.
Исследовательский ноутбук сохраняет отдельную модель и не заменяет Pipeline приложения.

## Оценка качества

Метрики взяты из фактического запуска `car-train` и файла `artifacts/metrics.json`.
Они рассчитаны на 31 отложенной строке:

| Метрика | Значение | Интерпретация |
| --- | --- | --- |
| MAE | 0,393960 лакха ₹ | Средняя абсолютная ошибка; примерно 39 396 ₹ |
| RMSE | 1,075610 лакха ₹ | Сильнее учитывает большие ошибки; примерно 107 561 ₹ |
| R² | 0,922428 | Доля вариации целевой цены, объяснённая относительно предсказания средним на этой выборке |

**R² = 0,922 не означает «точность 92,2%»** и не даёт гарантии ошибки для конкретного
автомобиля. Доверительные интервалы, сравнение с отдельной baseline-моделью,
качество по ценовым диапазонам, типам транспорта, топливу и продавцам не оценивались.
На других разбиениях или внешних данных качество может отличаться.

## Ограничения и неподходящие сценарии

- Небольшой исторический датасет и всего 31 тестовая строка ограничивают выводы о качестве.
- Смешаны автомобили и мотоциклы; отдельной оценки для этих групп нет.
- CNG представлен двумя строками и не различается с бензином в признаках.
- Не учитываются пробег, марка, модель, состояние, аварии и регион продажи.
- Модель не корректирует цену на инфляцию и изменения рынка после базового года.
- В интерфейсе можно ввести значения вне наблюдавшихся диапазонов; экстраполяция не проверена.
- Это оценка исторических данных в индийских рупиях, а не актуальная рыночная оценка в рублях.

Не использовать прогноз как единственное основание для реальной цены сделки,
кредитного решения, страхового расчёта или оценки другого рынка без соответствующей
валидации и обновления данных. Ошибки по подгруппам и возможные смещения выборки
не исследованы. Интерфейс не показывает интервал неопределённости.

## Воспроизводимость и обновление

```bash
poetry install
poetry run car-train --config configs/default.toml
poetry run car-predict --input data/raw/car_data.csv --output artifacts/predictions.csv
```

Настройки находятся в `configs/default.toml`, версии библиотек — в `poetry.lock`.
При изменении данных или параметров нужно повторно обучить модель, проверить её
качество и обновить эту карточку. Автоматический мониторинг и расписание переобучения
не реализованы.

SHA-256 датасета текущего запуска:

```text
7158342fbe118425b76015366307b744eae2de2b2e52ccf2241caf5f11794757
```

SHA-256 текущего файла модели:

```text
b9a9e027c1641bf426c989b1d81ef59493fa71a3380913189d2f3f9483a4d2c0
```

Хеш модели фиксирует конкретный артефакт; после повторной сериализации он может
измениться даже при совпадении прогнозов. Хеши и метрики отражают состояние на дату карточки.
