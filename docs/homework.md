## Пункт 3. Poetry, pre-commit и линтеры

- `pyproject.toml` описывает устанавливаемый пакет и команды терминала.
- Основные зависимости и зависимости разработки разделены; ноутбук — опциональная группа.
- `poetry.lock` фиксирует разрешённые версии зависимостей.
- `poetry.toml` размещает виртуальное окружение в `.venv`.
- Ruff проверяет и форматирует код; mypy проверяет типы пакета.
- `.pre-commit-config.yaml` запускает Ruff и mypy перед коммитом.
- `.gitignore` исключает окружение, кеши, сборки и локальные артефакты.

## Демонстрация преподавателю

```bash
poetry check --lock
poetry run pre-commit run --all-files
poetry run pytest
poetry run car-train
poetry run car-predict --input data/raw/car_data.csv --output artifacts/predictions.csv
poetry run streamlit run app.py
```

Покажите структуру пакета, конфигурацию, результат проверок, файл метрик и расчёт цены
в русском интерфейсе. Точные результаты обучения находятся в `artifacts/metrics.json`.

Технический рефакторинг не меняет пригодность исходных данных для реальных продаж.
Проект не содержит мониторинга, промышленного развёртывания или оценки на современном рынке.
